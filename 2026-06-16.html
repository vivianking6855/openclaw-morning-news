📖 名字解释

x402
Coinbase 主导的 agent 支付协议，让 AI 在无人确认下为 API 调用即时支付 USDC 微款项，已处理 1.69 亿笔交易。
AP4M
Mastercard 6月10日推出的 Agent Pay for Machines，整合卡片+银行账户+稳定币，为机器对机器交易提供结算保证。
Mythos-class
Anthropic 对 Claude Fable 5 的模型等级定位，代表"神话级"性能，意在区分普通模型与极致专业模型。
TEE
Trusted Execution Environment（可信执行环境），Coinbase Agentic Wallets 用 TEE 隔离保存私钥，agent 能花钱但人类能停。
VLA
Vision-Language-Action（视觉-语言-动作）模型，具身智能的核心架构，让机器人通过视觉理解+语言指令+动作执行完成任务。
SWE-bench
软件工程基准测试，衡量 AI 在真实 GitHub issue 上修复代码的能力。Claude Sonnet 5 以 92.4% 登顶。
MoE
Mixture of Experts（混合专家架构），只激活部分参数处理每个 token，671B 参数的 DeepSeek V4 仅激活 37B，推理速度提升 8 倍。
RAG
Retrieval-Augmented Generation（检索增强生成），让 LLM 先从外部知识库检索相关信息再生成答案，解决幻觉和知识时效问题。
ARR
Annual Recurring Revenue（年度经常性收入），SaaS 和订阅制企业的核心指标。Kimi 突破 1 亿美金 ARR 标志商业化进入新阶段。

💡 深度分析

趋势一：AI 公司 IPO 潮与估值重构
SpaceX 以史上最大 IPO 登陆纳斯达克首日暴涨 19%，马斯克成为全球首位万亿富豪。OpenAI 紧随其后秘密提交 IPO 申请，Anthropic 排队中。这标志着 AI 产业从"烧钱讲故事"进入"资本变现"阶段。但这些公司能否在公开市场维持高估值，取决于后续季度的财务数据。SpaceX 首日暴涨给出了积极信号，但 OpenAI 和 Anthropic 的估值能否撑住，还要看商业化能力的持续兑现。对投资者而言，AI 公司的估值逻辑正在从"技术潜力"转向"收入确定性"。
趋势二：Agent 从"能聊天"到"能花钱"——商务基础设施重构
2026 上半年最被低估的变革是 agent 进入"能花钱"阶段。x402（1.69 亿笔交易）、AP4M（30+ 伙伴）、Stripe Agent Toolkit 三大协议分别卡位链上微支付、跨轨道支付路由和传统卡片支付。这不仅是技术问题，更是商业基础设施的重构。当 agent 能自主购买 API、订阅服务、部署云资源，企业的采购流程、财务审批、合规审计都需要重新设计。DN42 案例的 6,531 美元账单只是开始，更大的挑战是建立"agent 财务纪律"——成本上限、速率限制、人类审核闸门的制度化。
趋势三：具身智能"量产元年"背后的分层竞合
2026 年被定义为具身智能量产元年，但行业已经出现清晰分层。宇树（四足+人形，全球出货量第一）、智元（3C 工厂场景）、银河通用（国家大基金加持，工业重载）、极佳视界（世界模型路线）各自占据不同生态位。这不是零和竞争，而是"技术路线×应用场景×资本结构"的三维分化。两部委启动万台级实训专项行动，意味着国家层面已经将具身智能视为"新质生产力"的战略支柱。从工厂拧螺丝到街头指路，物理 AGI 的落地节奏正在加快，但核心瓶颈仍然是数据——仿真数据与真机数据的融合质量，决定了模型的泛化能力上限。
